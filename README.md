# Calendari d’esdeveniments — AC3

Activitat del mòdul M0612 — Desenvolupament web en entorn client.
U1 — Fonaments de JavaScript.

## Aplicació publicada

[Obrir el calendari a GitHub Pages](https://ssabir94.github.io/calendariAC3/)

## Funcionalitats

- Calendari amb setmanes de dilluns a diumenge i navegació entre mesos.
- Indicadors del dia actual, del dia seleccionat i dels dies amb esdeveniments.
- Creació i eliminació d’esdeveniments per data.
- Persistència amb localStorage i JSON.
- Notificacions del sistema amb permís de l’usuari.
- Compartició de l’agenda amb Web Share API i alternativa al porta-retalls.

## Tecnologies

HTML, CSS i JavaScript sense frameworks.

## Comprovacions

S’han comprovat la navegació, els anys de traspàs, la gestió
d’esdeveniments, la persistència, les notificacions i la compartició.

Les dades es guarden localment al navegador utilitzat.
